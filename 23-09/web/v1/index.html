Como ler os shapes

(B, T, D) = batch (sequências processadas juntas), quantidade de tokens e dimensões do embedding. Aqui B = 1. H é o número de cabeças e V é o tamanho do vocabulário.

Dois níveis, explicitamente separados

Mini-GPT: os valores são calculados em JavaScript por um modelo pequeno (D = 8, H = 2, L = 2, vocabulário = 12, contexto máximo = 12), com pesos fixos não treinados. Os IDs são locais a este vocabulário. Não é uma execução do GPT-2 nem do PyTorch.

Referência GPT-2: shapes e parâmetros seguem a implementação de gpt.py, com QKV sem bias e cabeça de saída independente. O seletor altera essa referência; a rede pequena continua inspecionável.

A atenção retoma o capítulo 3 como componente do capítulo 4. O final oferece uma frase guiada, escolhida por nós, e o modo argmax, como generate_text_simple. A frase guiada não é aprendida ou prevista pela rede. Sem treinamento, as continuações não precisam fazer sentido.
